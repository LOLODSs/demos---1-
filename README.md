# Лесная · v1.7

Клиентская презентационная версия сайта ветеринарной клиники. Видимые демопометки убраны; текущие изображения и данные сохранены. Форма пока работает локально, без отправки данных.

## Анимации

- Однократное мягкое появление секций при прокрутке; на компьютере карточки появляются с небольшой последовательной задержкой, на телефоне — без задержки.
- Лёгкие реакции кнопок, карточек услуг и стрелок на наведение, без постоянного движения.
- Короткие переходы при открытии диалогов, FAQ, смене отзыва и параметров памятки.
- Плавная прокрутка к разделам. При prefers-reduced-motion декоративные анимации отключены; для печати всё содержимое отображается статично.
- Появления работают через один IntersectionObserver, без обработчика прокрутки. Фокус с клавиатуры немедленно показывает нужный элемент; без поддержки observer содержимое остаётся видимым.
- Логика: `src/hooks/useMotion.js`; оформление: блок `v1.7` в `src/styles.css`.

## Живая сцена

- Ваш ролик встроен в первый экран: справа от текста на компьютере; широким кадром под текстом на планшете, без лишней обрезки животных.
- Локальный MP4 H.264, 1280×720, около 9,4 секунды / 1,37 МБ. Звуковая дорожка удалена, стык повтора смягчён коротким перекрёстным переходом.
- Автозапуск без звука, playsinline, loop, отдельная доступная кнопка паузы/воспроизведения.
- Вне экрана или на скрытой вкладке воспроизведение приостанавливается.
- На телефоне, при prefers-reduced-motion или Save-Data видеоэлемент не создаётся; остаётся статичный кадр. В обычной сборке MP4 не запрашивается в этих режимах. В автономном HTML видео уже встроено в файл, поэтому его размер одинаков на всех устройствах.
- Если браузер блокирует автозапуск, можно нажать кнопку воспроизведения. При ошибке загрузки остаётся постер.
- «Срочно» — спокойная вторичная кнопка с тонкой рамкой и мягкой бордовой подложкой, без предупреждающего треугольника; срочный сценарий и его предупреждение сохранены.

## Открыть

- `preview.html` — автономная версия: откройте файл в браузере, все изображения встроены.
- `dist/` — готовая сборка для статического хостинга.
- `src/` — исходники React, `public/images/` — изображения.

```bash
npm ci
npm run dev
# Production:
npm run build
npm run preview
npm test
```

Node.js 20 или новее. Папка `node_modules` в архив не включена.

## Заменить содержимое

- Контакты, услуги, цены, специалисты, отзывы, FAQ и галерея: `src/data.js`.
- Основной текст и структура: `src/App.jsx`.
- Палитра и типографика: CSS-переменные в начале `src/styles.css`.
- Последний блок стилей `v1.4` содержит актуальную визуальную доводку.
- Ролик первого экрана: `public/videos/hero-pets.mp4`, постер: `public/images/hero-film-poster.webp`. Меняйте их совместно и проверяйте обе морды при кадрировании.
- Статичное мобильное фото: `hero-pets-compact.webp` (674×588). Старые `hero-pets.webp` и `hero-pets-mobile.webp` сохранены как исходные варианты, но первый экран v1.5 использует видеопостер и мобильный кадр.
- Логика воспроизведения и запасных режимов: `src/components/HeroMedia.jsx`. Блок стилей `v1.5` расположен после визуальной доводки v1.4.
- После замены фото или данных выполните `npm run build`: он обновит и `dist/`, и автономный HTML.

Перед публичным запуском замените примеры реальными сведениями, подключите обработчик записи и настройте обработку персональных данных. В этой презентационной версии видимые демопометки убраны по запросу. Кнопка «Срочно» открывает локальную форму и не вызывает экстренную помощь. Итоговый статус прямо сообщает, что заявка не отправлена.

## Адаптив и доступность

- На телефоне отдельная прокручиваемая область `.site-scroll` и отдельная строка панели действий; содержимое не уходит под кнопки. Якоря и липкая шапка работают внутри области.
- Навигация клавиатурой, focus-visible, управление диалогами, возврат фокуса, reduced motion.
- В печати отображается только выбранная памятка.
- Все изображения и видео локальные; внешние сервисы, отправка формы и постоянное хранение данных отсутствуют.

## Проверка

`qa/REPORT.md` — результаты. `qa/smoke.mjs`, `qa/features.mjs`, `qa/refinement.mjs` — браузерные тесты (нужны Playwright и Chromium в среде проверки). `npm test` работает с зависимостями проекта и проверяет данные, ресурсы и заданные контрастные пары.
